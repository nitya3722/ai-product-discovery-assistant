# 🤖 AI-Powered Product Discovery and Sales Assistant

A simple web-based product recommendation assistant designed to help customers discover suitable products based on their needs and preferences.

## 📌 Project Overview

Online shopping platforms offer thousands of products, which can make it difficult and time-consuming for customers to find the right product.

This project provides a simple product discovery assistant where users can describe what they are looking for. The system analyzes their requirements and displays relevant product recommendations.

## 🎯 Project Objectives

- Help customers discover products quickly.
- Reduce the time required to search for products.
- Provide recommendations based on customer requirements.
- Improve the online shopping experience.
- Support customer engagement and potential sales.
- 
- ## ✨ Features

- 🔎 Requirement-based product search
- 💡 Product recommendations
- 💰 Product price display
- 📋 Product feature information
- 🎯 Keyword-based matching
- ⚠️ Helpful response when no suitable product is found

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

- ## ⚙️ How It Works

1. User enters their product requirement.
2. The system analyzes the entered keywords.
3. Matching products are identified.
4. Recommended products are displayed.
5. The user can view the product price and features.

### Example

**User input:**

> Budget phone with good camera

**System output:**

- Smartphone A
- Price: ₹15,999
- Features: Good camera, long battery life
- Why recommended: Matches the user's requirements.

- ## 🚀 How to Run

1. Open the GitHub repository.
2. Download or clone the repository.
3. Open the `index.html` file in a web browser.
4. Enter your product requirement.
5. Click **Find Products**.
6. View the recommended products.
